Architectural Comparison

Dimension Frontend Layer (Client) Backend Layer (Server)
Execution Environment User's web browser (V8 / SpiderMonkey / WebKit) Node.js runtime server (Localhost or Cloud VM)
API Key Security ❌ Vulnerable (Keys in client code can be viewed in DevTools by anyone) ✅ Secure (Keys stored in environment variables, never sent to client)
Primary Role User Experience, event listeners, accessibility, responsive styling, markdown formatting API routing, authentication, business logic, payload conversion, rate limiting, error recovery
Data Handled UI state, active thread messages, draft inputs LLM provider payloads, secrets, server logging, token metrics
Supabase Integration Public Anon Key (SUPABASE_ANON_KEY) protected by Row-Level Security (RLS) Service Role Secret (SUPABASE_SERVICE_ROLE_KEY) with direct database administration
Environment (.env) frontend/.env: SUPABASE_URL, SUPABASE_ANON_KEY, API_BASE_URL backend/.env: PORT, GEMINI_API_KEY, OPENAI_API_KEY, SUPABASE_SERVICE_ROLE_KEY
Files in Project frontend/index.html, style.css, app.js, .env backend/server.js, controllers/, services/, routes/, .env
